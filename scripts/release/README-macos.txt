VRift - Hacknet extension editor
================================

1. Unzip this folder.
2. Drag VRift.app to Applications (or run it from anywhere).
3. The app is not notarized, so the first time: right-click VRift.app -> Open -> Open.
   If macOS says the app is damaged, run:  xattr -dr com.apple.quarantine /path/to/VRift.app

Works on Intel and Apple Silicon Macs.
