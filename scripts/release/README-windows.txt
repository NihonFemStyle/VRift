VRift - Hacknet extension editor
================================

1. Unzip this folder anywhere (for example your Desktop or Documents).
2. Double-click VRift.exe.

No installation needed. VRift uses Microsoft Edge WebView2, which is already part of
Windows 10 and 11. If VRift does not start, install the WebView2 Runtime from
https://developer.microsoft.com/microsoft-edge/webview2/

Windows SmartScreen may warn the first time because the program is not code-signed:
click "More info" -> "Run anyway".
