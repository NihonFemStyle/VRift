# VRift documentation

This directory contains the detailed documentation for VRift, a visual editor for Hacknet extensions.

## Choose a guide

- [User guide](user-guide.md) — install VRift, open or create an extension, edit files, validate a project, and use the built-in terminal.
- [Architecture](architecture.md) — understand the React/Tauri design, project model, XML round-tripping, indexing, validation, and filesystem boundary.
- [Development guide](development.md) — set up a development environment, run checks, add features, and understand project conventions.
- [Troubleshooting](troubleshooting.md) — solve common build, launch, library, editing, and validation problems.
- [Custom schemas](custom-schema.md) — add form support and validation for tags supplied by Pathfinder mods.
- [Contributing](../CONTRIBUTING.md) — development workflow, project invariants, checks, and pull-request expectations.
- [Security policy](../SECURITY.md) — supported versions and private vulnerability reporting.

The repository [README](../README.md) remains the short project overview, build quick start, release process, and feature summary.

## Documentation scope

The guides describe the behavior of VRift 1.1.0 as implemented in this repository. Hacknet extension format details are documented only where they affect VRift; for game-format reference material, use the official Hacknet Extensions guide linked from VRift's Help menu.
